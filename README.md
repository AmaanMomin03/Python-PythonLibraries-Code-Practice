SwiftMart Sales Analysis using Pandas

This project demonstrates basic data analysis using Python Pandas.
The goal is to analyze product orders from different regions and identify high-quantity sales.

Problem Statement

SwiftMart operates in multiple regions and wants to understand which zones are placing the most product orders.

Tasks performed:

Create a Pandas DataFrame
Filter orders where quantity > 5
Group data by region
Calculate total quantity sold
Sort regions based on total quantity
